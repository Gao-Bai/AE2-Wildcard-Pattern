# v2.2.0 — 通配样板（首个公开发行版）

**一张样板 = 一套规则。** 规则存在通配样板自己的 NBT 里，运行时由「通配样板供应器」在内存里展开成具体配方，
不用再为每种材料各编一张样板。

## 本版亮点

**1. 合成表可配置**

三个物品（通配样板编码器 / 通配样板供应器 / 空白通配样板）的配方不再写死，改由配置在服务器启动时生成，
`/reload` 后自动重新注入：

```toml
[recipes]
	patternEncoderEnabled = true
	patternEncoderIngredients = ["ae2:quartz_glass", "#forge:ingots/gold", "ae2:quartz_glass",
	                             "ae2:calculation_processor", "ae2:blank_pattern", "ae2:calculation_processor",
	                             "ae2:quartz_glass", "#forge:ingots/gold", "ae2:quartz_glass"]
	patternEncoderCount = 1
	# 供应器与空白通配样板同理；enabled = false 即整体关闭该配方
```

- 材料写法：`"ae2:quartz_glass"`（物品）、`"#forge:ingots/gold"`（标签）、`""`（空槽），9 项按行读；
- 空白的边缘行列自动裁掉，写 2×2 就是 2×2；
- 写错的物品/标签会在 `logs/latest.log` 里告警并当空槽处理。

**2. 空白样板拆成两个开关**

| 配置 | 默认 | 行为 |
| --- | --- | --- |
| `encodeRequiresBlankPattern` | `true` | 关闭后没有任何空白样板也能编码 |
| `encodeConsumesBlankPattern` | `true` | 关闭后需要持有但**不消耗**（当催化剂） |

## 功能总览（首个发行版包含的全部内容）

- **一张通配样板承载一套规则**：原料 / 产物 / 排除三个标签页，随时右键修改；
- **四种匹配器**：具体物品、`#标签`（矿物辞典）、族通配（`ingot*`、`plate*`…）、`@模组`（默认关闭）；
- **组**：同一组的原料与产物绑定同一个材料（铁配铁、锡配锡），不同组各自独立组合；
- **排除**：具体物品 / 产物 / 材料名 / 模组 / NBT / 原料×产物组合，在实例化**之前**求值；
- **不消耗**：原料可设为不消耗，合成后退回 ME 网络；
- **运行时惰性实例化**：编码时只写入一张样板，规则展开全部在内存里并按「规则内容 + 标签版本」缓存，
  不生成具体样板物品；单张默认最多展开 256 条（可配置）；
- **供应器返回槽**：机器自动弹出的产物被注入 ME 网络，行为与 AE2 原版样板供应器一致；
- **不干扰原版流程**：通配样板不是 AE2 样板，原版编码器既不能生成也不能编辑它；
  模组没有修改 AE2 任何类（零 mixin）；
- **界面**：按 AE2 15 的配色规范绘制，`C/O/A/N/X` 悬停有说明、按钮行 `?` 打开完整图例；
  支持从物品栏拖入、Ctrl+点击物品栏、从 JEI 拖入三种快速录入；
- **服务端权威 + 中英双语**：规则存在物品 NBT（服务端），客户端只负责显示；报错/警告全部按客户端语言渲染。

## 快速上手

1. 合成「通配样板编码器」，放地上右键打开编辑器；
2. 原料页点 `+` → 选「族通配」→ 输入 `ingot*`；产物页加 `plate*`，两边保持 `A` 组；
3. 点「编码」→ 得到**一张**通配样板；
4. 合成「通配样板供应器」放进 ME 网络并接上频道，拿着通配样板右键装入；
5. 在合成终端请求铁板/铜板…… 合成 CPU 会按规则规划，并把输入推进相邻机器。

## 已知限制

- **NBT 精确匹配**：规则里的 NBT 条件必须被网络中的物品满足（AE2 按精确键取物），这是 AE2 的机制限制；
  从 JEI / 物品栏录入会自动带上 NBT，也可按 `N` 手动修改；
- **可选输入默认关闭**：AE2 没有「可有可无的输入」概念，只能靠多实例化表达，开启后上限 2 层；
- **`@模组` 匹配器默认关闭**：可能命中数千个物品，开启请配合上限；
- **返回槽依赖机器主动弹出**：供应器会把输入推进相邻机器，但机器需要开启自动弹出（或本身会把产物推回）才能回流；
- 单张样板默认最多展开 **256** 条配方，超出会提示截断（`maxInstances` 可调）。
