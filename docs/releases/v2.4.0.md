# v2.4.0 — 增加 `ID*` 模式匹配器（跨材料配对）

本次解决的是"通配没通配"的问题：原先只能匹配具体物品 / 某个标签 / 某个族，而按标签反查出来的常常是
**某个具体材料**的标签，规则就被钉死成「这个锭 → 这个导线」。

前置不变：Minecraft 1.20.1、Forge 47+、**AE2 15.x 必需**，JEI 15.x 可选。旧规则与旧样板完全兼容。

## 新增：`ID*` 模式匹配器

值是**物品 ID 模式**，第一个 `*` 捕获的文本会作为**变体（材料名）**参与组绑定：

| 模式 | 匹配 | 变体 |
| --- | --- | --- |
| `gtceu:*_single_wire` | `gtceu:copper_single_wire`、`gtceu:black_steel_single_wire`… | `copper`、`black_steel`… |
| `*_ingot` | 所有 `_ingot` 结尾的物品 | 前缀 |

于是「任意锭 → 对应材料的导线」终于成立了：

```
原料  ingot*                  (A 组)
产物  gtceu:*_single_wire     (A 组)
结果  黑钢锭 → 黑钢导线、铜锭 → 铜导线、锡锭 → 锡导线 ……
```

**从选中物品自动推导**：在 `ID*` 模式下，选中某个导线后，列表会给出把该物品所属标签里的材料名
替换成 `*` 的模式（`gtceu:copper_single_wire` + 标签 `forge:wires/copper` → `gtceu:*_single_wire`）。

**提示**：模式不含 `*` 时提示 `ID 模式需要包含 '*'`；匹配不到任何物品时提示 `没有物品 id 匹配这个模式`。

## 操作步骤（任意锭 → 线材）

1. 原料页 `+` → `族通配` → `ingot*`，组设 `A`；
2. 产物页 `+` → `物品` 模式搜 `single wire` → 选中任意导线（如 `gtceu:black_steel_single_wire`）；
3. 切到 **`ID*`** → 列表顶部给出 `gtceu:*_single_wire` → 选中 → 组也设 `A`；
4. 编码 → 装进通配样板供应器 → 请求黑钢导线：黑钢锭配黑钢导线。

## 修正：恢复"输入即内容"

2.3.1 给「使用输入的内容」加了严格校验，等于去掉了手动输入任意内容的能力。本版恢复为**总是提供**
（tag、物品 id、ID 模式都能直接输入确认），但**固定排在列表最后**，第一行永远是真实搜索结果，
不会误建空规则。

## 其余（沿用 2.3.x）

- 无命中时不再回退成"该类型全部条目"；
- 物品 id 与标签支持分词匹配（`gtceu:single_wire` / `single wire` → `gtceu:tin_single_wire`）；
- 选中物品后可反查它所属的标签与族；
- 物品名去掉格雷 `includeAmountInItemName` 的 `1x` 前缀；
- 状态行只显示计数，鼠标悬停用 tooltip 显示完整配方与警告。

## 已知限制

NBT 精确匹配；可选输入默认关闭（开启上限 2 层）；`@模组` 匹配器默认关闭；
返回槽依赖机器主动弹出；单张样板默认最多展开 256 条配方。
